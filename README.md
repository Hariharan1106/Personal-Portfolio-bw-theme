# Personal Portfolio Website

This project is a personal portfolio website for Anantha Hariharan V. It is built with plain HTML, CSS, and JavaScript, so it is simple, fast, and easy to customize.

## What this project does

This website shows:
- a home section with a short intro
- an about section
- skills and experience timeline
- selected project cards
- contact details and a message form
- dark/light theme toggle
- smooth scrolling and animations

## Project structure

- `index.html` — all page content and sections
- `portfolio.css` — design, layout, animations, colors, responsiveness
- `portfolio.js` — theme switching, navbar, scroll effects, animations, contact form behavior
- `requirement.txt` — currently not used for this project

## How to run it

Because this is a static website, you do not need to install heavy packages.

Option 1: Open directly
- Open `index.html` in your browser.

Option 2: Run a local server
- Open a terminal in this folder
- Run:

```bash
python -m http.server 8000
```

- Then visit:

```text
http://localhost:8000
```

## How to customize it

### Change your personal info
Edit the text inside `index.html`:
- name
- role
- about section
- experience timeline
- project links
- contact links

### Change the design
Edit `portfolio.css`:
- colors
- spacing
- font styles
- section layout
- mobile menu behavior

### Change JavaScript behavior
Edit `portfolio.js`:
- theme toggle behavior
- scroll reveal effects
- custom cursor
- contact form response

## Features included

- Responsive layout for desktop and mobile
- Dark and light theme switch
- Animated section reveals
- Smooth scrolling between sections
- Interactive project and skill cards
- Floating custom cursor effect
- Contact form interaction
